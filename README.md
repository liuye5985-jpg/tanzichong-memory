# 炭子冲 · 故居回响

刘少奇故居主题二维场景化交互体验。课程：交互设计及可行性。

- 在线体验：https://tanzichong-memory.pages.dev/
- GitHub：https://github.com/liuye5985-jpg/tanzichong-memory
- 无需安装 npm 或构建；静态 HTML/CSS/JavaScript，所有运行资源本地随项目提供。

## 作品概念

以“一扇门，一段时光”为叙事，借鉴用户所提供录屏中的“身体动作打开入口”机制，把它转译为推开木门、走入院落、在书房读屋、回望历史的数字参访过程。画面采用木、瓦、土墙、纸张和金色光线，以低饱和青灰、深木色和暖纸色维持整体秩序。

背景为AI辅助创作的艺术化湘中农舍场景，不是刘少奇故居实测复原，不将画面中的家具布局当作史实。未使用参考录屏中的影视画面、人物图像或音轨。

## 四章与交互

1. **叩门**：拖拽木门向两侧展开；按钮亦可进入。MediaPipe身体模式中，双腕间距按肩宽归一化，持续展开双臂约0.65秒进入院落。
2. **入院**：点击3个线索；身体模式中，手停在标记附近约1.05秒触发。阅读后进入手札。滑动光影刻度改变院落亮度，身体模式以双腕高度控制光影。
3. **读屋**：指针/右手位置影响书房局部光晕，触碰画面产生微尘。打开三页史料笔记，以按钮或左右箭头翻页；身体模式中单独举起右手向后翻页，单独举起左手向前翻页。每次翻页后手先放下，再举起触发下一次。
4. **回望**：四个时间节点整理已读内容。手札展示6条线索的阅读状态，并导出1400×1000的PNG参访纪念卡。

环境声为Web Audio合成风声与钟声，需要手动开启。不是现场录音。支持键盘、触屏和鼠标，摄像头不是进入作品的前提。

## 本地运行

macOS双击 `启动作品.command`。如果macOS阻止脚本，使用终端进入本目录：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

访问 http://127.0.0.1:8766/ 。停止服务按Ctrl+C。不要使用file://打开后测试相机。

快捷键：1—4选择章节，V切换相机，M切换声音，书页中←→翻页，Esc关闭弹窗。木门支持焦点下左右方向键及Enter。

## 技术和课程对应

- HTML：全屏场景、章节导航、资料弹窗、阅读笔记、操作说明。
- CSS：响应式布局、木门展开、光影层、画面转场和纸张排版。
- p5.js **1.11.10**：实际创建并持续绘制二维Canvas，处理微尘、点击粒子、水纹意象及随指针变化的光晕。
- MediaPipe Tasks Vision **0.10.21**：本地Pose Landmarker Lite识别鼻、肩、腕等关键点，控制开门、光影、手势选择和翻页。
- assets：两个背景图、姿态模型、图标。vendor：p5.js、MediaPipe JS/WASM及许可。
- GitHub保存源码；Cloudflare Pages发布静态项目。

没有采用Three.js、WebGL场景建模或三维漫游。空间感通过二维背景、光影、木门CSS变换和交互叙事形成。

## 性能与隐私

p5画面上限30fps，减少动态偏好下降至15fps，像素比上限2；65个常驻微尘，点击粒子上限150。识别最多约11次/秒，单人。尽量用GPU，失败后尝试CPU。手腕位置平滑，置信度不足不触发动作；翻页需要回到中立动作，停留选择每次进入目标只触发一次。

相机仅本地推理，不上传、不保存，不申请麦克风。切到后台、离开页面、识别中断或手动关闭时停止相机轨道。阅读状态只存在浏览器localStorage，可在手札中重置。无账号、无统计代码、无后端。

所有运行资源都在项目内，下载项目后本地启动不依赖CDN；首次加载模型可能需要几秒。相机需要HTTPS/localhost和系统/浏览器允许。真人识别的稳定性取决于光照、设备和站位，建议展示前现场验证。

## 发布设置

Cloudflare Pages：项目`tanzichong-memory`，生产分支main，框架None，构建命令留空，输出目录`.`。

当前版本通过Wrangler Direct Upload部署，代码另同步GitHub。GitHub与线上版本本次保持一致；后续仅推送GitHub不会自动触发此Direct Upload项目，需要重新运行：

```sh
npx wrangler pages deploy . --project-name tanzichong-memory --branch main
```
